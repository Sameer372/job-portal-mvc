# Job Portal – Multi-Role Recruitment Platform

A PHP-based, MVC-structured job portal designed to connect job seekers, employers, recruiters, and administrators through a unified recruitment platform.

## Overview

The Job Portal is a multi-role web application that streamlines recruitment by providing dedicated modules for different types of users.

The platform allows job seekers to explore opportunities and apply for jobs, employers to publish vacancies and review applications, recruiters to manage candidate searches and hiring activities, and administrators to oversee platform operations.

## User Roles & Features

- **Job Seeker**
  - Explore available job opportunities.
  - Apply for suitable positions.
  - Manage job-seeking activities.

- **Employer**
  - Publish job vacancies.
  - Manage job postings.
  - Review applications from candidates.

- **Recruiter**
  - Search and filter candidates.
  - Manage recruitment activities.
  - Handle hiring processes for multiple clients.

- **Administrator**
  - Oversee platform operations.
  - Manage platform access and user roles.
  - Maintain platform security and governance.

## Key Features

- Multi-role authentication system.
- Dedicated modules for four user roles.
- Job posting and application management.
- Candidate search and filtering.
- Session-based authentication.
- Role-Based Access Control (RBAC).
- Shared frontend design and resources.
- MVC-based application structure.
